# Project Statement

## Problem Statement
Daily water use is easy to ignore because it is spread across many small activities. This project provides a simple way to estimate direct daily use from common activities.

## Objectives
1. Build a practical Python application.
2. Apply functions, dictionaries, conditions, loops and modules.
3. Provide an understandable water-use breakdown.
4. Handle invalid user input.
5. Give useful water-saving suggestions.

## Functional Requirements
1. Input and validation
2. Water-use calculation
3. Result analysis and classification
4. Terminal visualization
5. Recommendations

## Target Users
Students and other users interested in understanding everyday direct water use.

## Scope
The project covers direct household-style activities. It does not calculate agricultural, industrial or complete virtual water footprints.
