# Water Footprint Check

## Overview
Water Footprint Check is a Python command-line project that estimates direct daily water use from common activities. It also identifies the largest contributor and gives simple conservation suggestions.

## Features
•User input and validation
•Activity-wise water calculation
•Low / Moderate / High classification
•Largest-use activity
•Terminal bar chart
•Personalized tips
•Basic testing
•Optional text report

## Run
Use Python 3:
python main.py

## Test
python tests.py

## Files
•main.py - controls the program
•input_handler.py - takes and validates input
•calculator.py - performs calculations
•analyzer.py - classifies and analyzes results
•visualizer.py - displays results
•tips.py - gives suggestions
•data.py - stores factors and names
•report.py - saves a simple text report
•tests.py - checks important functions

## Limitation
The factors are simplified educational assumptions. Real water use varies with appliances, habits and local conditions, so the result is only an estimate.

## Learning
The project demonstrates variables, dictionaries, functions, loops, conditions, modules, validation, error handling and testing.
