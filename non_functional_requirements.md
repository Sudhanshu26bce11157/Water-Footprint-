# Non-functional Requirements

1. **Usability:** Prompts and output should be easy for a beginner to understand.
2. **Performance:** The calculation should finish immediately for normal input.
3. **Reliability:** Invalid input should be handled without crashing the program.
4. **Maintainability:** Different tasks are separated into small modules.
5. **Resource efficiency:** The project uses only the Python standard library.
6. **Security/privacy:** No passwords, payment details or sensitive personal information are collected.
7. **Scalability:** New activities can be added through the data module.
